Meta 发布开源 30B 编码 Agent 模型 Muse Glimmer

Meta 研究院发布了 Muse Glimmer，一个 的 30B 参数本地编码模型，定位为「开放 Agent 模型」，强调编码能力与本地可部署。素材没有给出具体基准分数，但 30B 的规模意味着它瞄准的是需要自托管、又不想牺牲编码质量的中高端场景。

为什么值得关心：编码 Agent 的模型选择正从闭源 API 扩展到本地权重，直接影响数据合规与单位经济性，值得把它纳入模型选型和定价模型的重估。

Docker 推出面向 AI Agent 的一次性隔离沙箱

Docker 发布了 Docker Sandboxes 产品，为 提供可随时销毁的隔离运行环境。Agent 在执行代码、调用工具时不再直接暴露在宿主机上，用完即弃，从设计上降低了误操作和恶意行为造成的破坏。

为什么值得关心：隔离与安全是 Agent 产品落地的关键风险项，基础设施厂商的入场让该能力的获取成本下降，应该把这个选项纳入架构选型。

Oracle 禁止 AI 生成代码进入 OpenJDK

Oracle 宣布禁止 AI 生成代码直接提交进 OpenJDK 代码库，尽管其高管 Larry Ellison 曾声称 Oracle 自己不用 AI 写代码。这一政策具体的适用边界和审查机制尚未公开，但已经明确划出了一条线。

为什么值得关心：代码生成工具的输入输出可能带版权风险，开源项目的政策变化会直接影响你能否在关键依赖里使用 AI 生成代码，进而影响研发效率和法律风险。

笔记应用 TLDV 泄露超 18 万条 AI 会议录音

安全研究者发现 AI 会议笔记应用 TLDV 存在一个漏洞，导致超过 181,000 条会议录音被公开暴露。这些录音包含真实商务对话，属于高度敏感数据。目前具体漏洞类型和影响范围尚待更多披露。

为什么值得关心：AI 应用处理语音、会议等隐私数据的合规风险极高；安全事件会重塑用户信任，也提示你在选择第三方供应商时把安全能力作为硬指标。
